Watcher Test Data

Controllable JSON endpoints for testing the prediction engine watcher. Change values below, then watch the watcher detect changes.

How to Use

# 1. Register a watcher endpoint pointing at this GitHub Pages URL
curl -X POST http://localhost:6080/v1/forecast/<FORECAST_ID>/watch \
  -H "Content-Type: application/json" \
  -d '{
    "endpoint_key": "test:unemployment",
    "service": "github-pages",
    "url": "https://danielproj.github.io/watcher-test-data/data/unemployment.json",
    "poll_frequency_minutes": 1,
    "notify_strategy": "on_change"
  }'

# 2. Change the data (bumps unemployment from 4.3 → 5.1)
./scripts/update-data.sh unemployment '{"latest":{"date":"2026-03","value":5.1}}'

# 3. Or use the GitHub API directly
gh api repos/danielproj/watcher-test-data/contents/data/unemployment.json \
  --method PUT \
  --field message="Bump unemployment to 5.1" \
  --field content="$(base64 < new-data.json)" \
  --field sha="$(gh api repos/danielproj/watcher-test-data/contents/data/unemployment.json -q .sha)"

# 4. Wait for watcher poll cycle, then check updates
curl http://localhost:6080/v1/forecast/<FORECAST_ID>/updates
